# Ta raquette de padel 🎾

Une page web animée en 3D (Three.js) pour annoncer un cadeau :

1. le terrain de padel se trace en traits blancs sur fond noir, la caméra suit le tracé ;
2. le vrai terrain sort du sol ;
3. « PRÊT À FAIRE DES DOUBLES FAUTES ? » ;
4. BOUM : la raquette apparaît avec un bon cadeau de **320 €** pour s'acheter sa future raquette.

Tout tient dans un seul fichier : [`index.html`](index.html). Il suffit de l'ouvrir dans un navigateur (connexion Internet requise pour charger Three.js et les polices).

Astuces :
- `index.html#surprise` saute directement à la révélation ;
- `index.html?t=8` fige l'animation à 8 s.
